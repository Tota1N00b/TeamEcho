# Team Echo

Team Echo is a virtual playground for **Project “Echo”**, an interactive installation project exploring how misinformation, AI, social media, and digital echo chambers shape the way people perceive reality.

The website extends the physical installation into an online space, allowing visitors to explore Team Echo’s prototypes, design process, team members, and interactive experiments across different devices.

## Live Website

View the website here:

https://tota1n00b.github.io/TeamEcho/

## About the Project

**Echo** is an immersive interactive installation that reflects on power, misinformation, and the fragmented digital environments we experience every day.

Through projection, light, sound, motion, and interactive systems, the project creates a beautified but distorted space where visitors are invited to question what they see, hear, and believe. The installation uses visual and audio-reactive technologies to represent the overwhelming flow of information in digital culture.

The website functions as a digital extension of this experience. It presents simplified, interactive versions of the installation prototypes so visitors can explore the project beyond its physical form.

## Website Concept

Welcome to Team Echo’s virtual playground, a creative hub where art and technology converge in the digital sphere.

The website was built with custom **HTML**, **CSS**, and **JavaScript**, using creative coding frameworks such as **p5.js** and **RNBO.js** to support dynamic visuals, sound interactions, and playful user input.

The site is designed to be:

- **Fully responsive**, supporting desktop, mobile, ultra-wide displays, and smaller screen formats
- **Dynamic and interactive**, encouraging visitors to click, move, touch, listen, and explore
- **Process-driven**, showing how Team Echo’s prototypes evolved over time
- **Connected to the physical installation**, translating spatial, visual, and sonic experiences into a browser-based format

## Key Features

### Fully Responsive Design

The website adapts across different screen sizes, from desktop to phone, and even wider displays or small device formats.

### Dynamic and Interactive Playground

The playgrounds are digital, simplified versions of Team Echo’s installation prototypes. They capture key features, visuals, and concepts from the physical work while offering playful browser-based interactions.

Visitors can switch between different playgrounds, explore project experiments chronologically, and observe how concepts and visual systems shift, combine, and evolve.

### About Echo & Team Echo

The website introduces the vision behind **Echo**, shares project insights, and highlights the collaborative efforts of Team Echo.

Team members include:

- **Binna Lee** — Creative Director
- **Cici Zhang** — Visual Designer
- **Roy Yang** — Creative Technician
- **Jay Tobin** — Sound Designer

### Sonic Interactions

The website also explores the auditory dimension of Team Echo’s playground.

Using **RNBO.js**, the site features generative soundscapes that respond dynamically to mouse interaction. These browser-based sonic interactions echo the physical installation, where sounds adapt to movements and ambient noises, creating a unique experimental auditory experience with each visit.

## Prototype System

### Prototype 1: Light Cube

The initial prototype features a single cube with bright lights moving along strings.

Visitors can move the mouse around the canvas to distort the cube from different angles and alter the speed of the light flow. This prototype introduces the foundational visual and interactive language of the project.

### Prototype 2: Pattern Sphere

Prototype 2 introduces a semi-sphere structure based on a truncated icosahedron.

Moving and changing patterns appear across the mesh. Clicking on dark pattern clusters opens and closes the patterns, revealing colorful, flickering flows inside. This prototype expands the project’s visual system from a linear cube structure into a more organic and networked form.

### Latest Prototype: Multi-Cube Thread System

The latest prototype features multiple cubes with bright lights moving along threads.

Long-pressing triggers colorful visual effects, showing Team Echo’s continued development in interactive visual design, spatial rhythm, and responsive behaviors.

## Design Process

The design process focused on translating a physical, multi-sensory installation into a digital experience that could still feel spatial, playful, and exploratory.

The website was developed around three core goals:

1. **Preserve the feeling of the installation**  
   The digital playgrounds echo the installation’s use of light, distortion, motion, and sound.

2. **Show the evolution of the project**  
   Visitors can move through different prototypes and see how the forms, interactions, and concepts developed over time.

3. **Make the project accessible online**  
   Since not everyone can experience the installation in person, the website creates a way to understand the project’s atmosphere, interaction logic, and design journey through the browser.
